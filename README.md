# state-features-functions-interactive
Інтерактивний навчальний модуль "Поняття, ознаки та сутність держави" з курсу правознавства для учнів 10 класу

## 📌 Про інструмент
Цей веб-тренажер розроблений для самостійної або групової роботи учнів із метою закріплення теми «Держава, її ознаки, сутність, функції, види суверенітету, а також співвідношення правової держави та громадянського суспільства».

## ✨ Особливості інтерактиву
* **Інтерактивні флешкартки** для повторення ключових термінів.
* **Вправи на встановлення відповідності** та розподіл ознак.
* **Матриця форм і методів** здійснення функцій держави.
* **Графічні завдання** на аналіз співвідношення понять.
* **Підсумковий тестовий контроль** із миттєвою перевіркою та розгорнутими поясненнями.
* **Збереження прогресу** учня в локальному сховищі браузера (localStorage).
